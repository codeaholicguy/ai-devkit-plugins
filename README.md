# AI DevKit Plugins

Plugin packages for [AI DevKit](https://github.com/codeaholicguy/ai-devkit).

## Packages

| Plugin | Description |
|---|---|
| [`packages/memory-dashboard`](./packages/memory-dashboard) | Dashboard UI plugin for browsing AI DevKit memory |
| [`packages/task-manager`](./packages/task-manager) | Task tracking plugin for AI DevKit |

## Installation

Plugins are installed through the AI DevKit CLI and resolve as npm packages at
runtime — see the [plugins documentation](https://github.com/codeaholicguy/ai-devkit/blob/main/web/content/docs/14-plugins.md)
in the main repository.
